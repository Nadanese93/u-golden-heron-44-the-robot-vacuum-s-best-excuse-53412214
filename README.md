Entry for the [make.fun](https://make.fun) bounty **The Robot Vacuum's Best Excuse** ($2 prize): one line in which a robot vacuum explains why it missed a spot.

> "I spent three days stuck under the sofa. That spot can wait — I have seen things."

`main.py` (Python standard library only) writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
